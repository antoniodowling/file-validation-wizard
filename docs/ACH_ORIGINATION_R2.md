The parser recognizes case-insensitive declarations so lowercase standardized markers cannot evade their checks. PAYROLL has three discretionary suffix positions; alphabetic suffix characters remain uppercase under the standardized-field character requirement. PURCHASE is recognized within the descriptor, HCCLAIMPMT as the whole ten-column descriptor, and REVERSAL retains r1's within-field semantics. Other freeform descriptions are allowed. Descriptor absence never proves absence of payroll, purchase or healthcare purpose; actual purpose is not inferred from identity or freeform remittance text. TEL standing authorization remains external evidence.

HCCLAIMPMT declares healthcare classification only for this candidate. Non-prenotes require a present type-05 addenda and indicator 1; existing generic count/type/sequence/link checks still apply. [CMS transmittal R1351OTN](https://www.cms.gov/regulations-and-guidance/guidance/transmittals/downloads/r1351otn.pdf), 2014, corroborates the asterisk separators, trace type 1, mandatory TRN02/TRN03 and optional TRN04. The structural TRN check accepts a whole uppercase `TRN*1*trace*company~` segment with an optional fourth data element. It preserves the 80 payload columns and removes only final space padding before syntax evaluation. It checks the segment boundary and required reassociation elements, without claiming full ASC X12 5010 835 element lengths, code sets or business-guide conformance. Malformed prerequisites suppress dependent evaluation; prenotes make the healthcare rules not applicable.

The prior WEB/TEL loan, UN/EDIFACT and opt-in XML CTX source gates remain UNSUPPORTED with no verdict.
